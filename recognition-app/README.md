# Team Recognition Spring Boot Application

A Spring Boot application that allows users within an organization to send monetary recognitions (points/credits) to their teammates. Users can also redeem their accumulated balance.

## Features

*   User registration and login (email/password based).
*   Organization management (basic creation).
*   Users can recognize teammates by gifting a certain amount of their available credit.
*   Users can include an optional message with the recognition.
*   Users can view their current available credit balance.
*   Users can redeem their available credit.
*   Dashboard to access features:
    *   Search for users to recognize (by name or email).
    *   Send recognition.
    *   View current balance.
    *   Redeem balance.
*   Basic Spring Security for authentication and authorization.
*   In-memory H2 database for development.

## Technologies Used

*   Java (version specified in pom.xml, e.g., 17)
*   Spring Boot (version specified in pom.xml)
*   Spring Web
*   Spring Data JPA
*   Spring Security
*   Thymeleaf (for server-side templating of login and dashboard pages)
*   H2 Database (in-memory)
*   Maven (for build and dependency management)
*   JUnit 5 & Mockito (for unit testing)

## Setup and Running Instructions

**Prerequisites:**
*   Java Development Kit (JDK) version 17 or later.
*   Apache Maven 3.6.x or later.

**1. Clone the Repository:**
   ```bash
   # Replace with the actual repository URL if applicable
   git clone <repository-url>
   cd recognition-app
   ```

**2. Build the Project:**
   This will download dependencies and compile the source code.
   ```bash
   mvn clean install
   ```

**3. Run the Application:**
   ```bash
   mvn spring-boot:run
   ```
   Alternatively, you can run the main application class `com.example.recognitionapp.RecognitionApplication` from your IDE.

**4. Accessing the Application:**
   *   **Login Page:** [http://localhost:8080/login](http://localhost:8080/login)
   *   **Dashboard (after login):** [http://localhost:8080/dashboard](http://localhost:8080/dashboard)

**5. H2 Database Console (for development):**
   If `spring.h2.console.enabled=true` is set in `application.properties` (which it is by default in this project's setup):
   *   **H2 Console URL:** [http://localhost:8080/h2-console](http://localhost:8080/h2-console)
   *   **JDBC URL (default for this project):** `jdbc:h2:mem:testdb`
   *   **Username:** `sa`
   *   **Password:** `password`

## API Endpoints Summary

All API endpoints are prefixed with `/api`. Most endpoints require authentication unless otherwise specified.

*   **Organizations:**
    *   `POST /api/orgs`: Create a new organization. (Public)
        *   Request Body: `Org` entity JSON structure.
    *   `GET /api/orgs/{id}`: Get organization details by ID. (Public)

*   **Users:**
    *   `POST /api/users/register`: Register a new user. (Public)
        *   Request Body: `UserRegistrationRequest` JSON (`{ "firstName": "...", "lastName": "...", "email": "...", "password": "...", "orgId": ... }`)
    *   `GET /api/users/search?query={query}`: Search for users by name or email. (Authenticated)
    *   `GET /api/users/{id}`: Get user details by ID. (Authenticated, or adjust security as needed)
    *   `GET /api/users/email/{email}`: Get user details by email. (Authenticated, or adjust security as needed)
    *   `GET /api/users/me/balance`: Get the current authenticated user's available balance. (Authenticated)
    *   `POST /api/users/me/redeem`: Redeem an amount from the current authenticated user's balance. (Authenticated)
        *   Request Body: `RedemptionRequest` JSON (`{ "amount": ... }`)

*   **Recognitions:**
    *   `POST /api/recognitions/send`: Send a recognition to another user. (Authenticated)
        *   Request Body: `RecognitionRequest` JSON (`{ "recipientId": ..., "amount": ..., "message": "..." }`)
    *   `GET /api/recognitions/received`: Get a list of recognitions received by the current authenticated user. (Authenticated)
    *   `GET /api/recognitions/given`: Get a list of recognitions given by the current authenticated user. (Authenticated)

## Database Schema

The database schema is automatically generated by Hibernate based on the JPA entity definitions (located in `com.example.recognitionapp.model`). The `spring.jpa.hibernate.ddl-auto` property in `src/main/resources/application.properties` is set to `create` by default for development, meaning the schema is created each time the application starts.

The manually derived DDL (which should match the Hibernate-generated schema) can be found in `src/main/resources/schema.sql` for reference.
